# 砚台 · 角色书架

V1.4.1 试用版 · 创意与测试：阿砚 · 代码：Codex

原名「静读 · 角色书架」。提供独立扩展和酒馆助手脚本两种安装方式，只启用其中一种。

发布仓库：[ayan-atelier/yantai-bookshelf](https://github.com/ayan-atelier/yantai-bookshelf)。

## 安装与更新

最低要求：SillyTavern 1.16.0。

### 使用仓库网址安装

仓库文件上传完成后，在酒馆「扩展 → 安装扩展」粘贴以下地址：

```text
https://github.com/ayan-atelier/yantai-bookshelf
```

安装后刷新酒馆，在「扩展 → 砚台 · 角色书架」启用首页书架。之后可在同一设置里的「版本与更新」检查新版、更新或退回已发布的兼容版本。

从旧版迁移时先停用旧书架。旧版若通过解压安装，请把原 `jingdu-bookshelf` 扩展目录移到扩展目录外备份，再使用网址安装；保留书架设置，不要清除扩展数据。旧版若是酒馆助手脚本，先关闭旧脚本，避免两份书架同时运行。

### 酒馆助手版

从仓库的 `releases/` 目录下载 `yantai-bookshelf-v1.4.1-helper.json`，导入酒馆助手全局脚本库，只启用一份书架。此包已预填上述发布仓库；首次从 1.4.0 升级仍需要导入新版一次，之后可使用「版本与更新」。

### 解压安装

也可使用独立 ZIP 手动安装，但这类安装没有 Git 信息，需要先改用仓库网址安装才能在线切换版本。

1. 解压，取得 `jingdu-bookshelf` 文件夹。
2. 放到正在运行的酒馆目录：`SillyTavern/data/default-user/extensions/`。
3. 已安装旧版时，覆盖原来的同名文件夹，刷新酒馆。
4. 在「扩展 → 砚台 · 角色书架」确认显示「已加载 · V1.4.1」，开启「首页显示角色书架」。

正确文件位置：`SillyTavern/data/default-user/extensions/jingdu-bookshelf/manifest.json`。

为便于覆盖升级，安装文件夹仍叫 `jingdu-bookshelf`，请不要另建第二份。原有置顶、收藏、封面位置和存档显示名继续沿用。

如果你正在使用酒馆助手版书架，先关闭那份脚本，只启用一种安装方式。

多账户请将 `default-user` 换成当前账户目录。手机或远程访问时，把文件放在实际运行酒馆的设备上。不要套两层同名文件夹；ZIP 不导入主题、角色卡或正则。

## 功能

- 首页 3:4 竖版角色封面，显示名字、标签、存档数量与最近游玩时间。
- 点角色封面统一打开存档列表，无论有零个、一个还是多个存档；点某一份存档继续聊天。
- 角色置顶、星号收藏、角色名和标签搜索；置顶按点击先后排列。其余可按最近游玩、最近添加、最早添加、存档最多、名称排序；自动记住选择。
- 顶部左侧是「全部 / 收藏 / 排序」，右侧是原版首页。排序在按钮下方展开小菜单，勾选当前方式，默认最近游玩。搜索提示为「搜索角色名或标签…」，不搜索存档或聊天正文。
- 存档列表右上角可「＋ 新聊天」，通过酒馆原生功能另开一份独立存档。
- 每份存档右上角的垃圾桶可删除该存档。确认框列出显示名、原文件名和日期；删除正在打开的存档会先退出聊天。角色卡与其他存档保留，删完更新列表和数量。
- 调整封面裁切位置，原图不变。
- 存档预览略去常见思考标签、样式和脚本。铅笔只改书架显示名，不改原存档文件名。
- 点「原版首页」可切回原生页面，版本号下方的快捷按钮末尾有「书架」返回入口；聊天中可从输入栏的扩展菜单打开书架。
- 颜色与字体跟随当前酒馆主题。标题、新聊天和选中项使用主题正文色，辅助文字保持淡色。预览读取现有消息，不调用 AI。

## V1.4.1 试用版（2026-09-23）

- 自动记住上次选择的文件夹或未分类、收藏筛选和页码，关闭重开页面后继续停在那里。排序、每页 20/40 张继续沿用已有偏好。
- 按文件夹 ID 记忆，改名不影响；原文件夹已删除时回到全部；卡片减少导致页码越界时显示最后一页。
- 搜索是临时筛选，不保存搜索词；清空搜索后返回同一分类之前的页码。
- 在「扩展 → 砚台 · 角色书架 → 版本与更新」检查新版、查看简短更新内容、确认切换或退回上一兼容版本。首页不增加按钮，也不会在启动时检查或自动下载更新。
- 切换前保存一份书架设置备份（仅书架自己的配置）。回退保留当前分类、收藏、置顶、封面位置、显示名；只有相同数据格式的版本才提供切换。旧功能可能不显示新字段，但不会主动清空它们。
- 更新不写角色卡或聊天正文；生成/保存中拒绝切换。下载失败、助手包校验不符、设置无法确认保存时停止。服务端切换后若结果不明，会提示刷新核对，避免重复写入。

### 在线更新的首次接入

此包已写入发布仓库 `https://github.com/ayan-atelier/yantai-bookshelf`。位置记忆安装后即可使用；在线检查需要仓库中的版本清单与发布包已经上传，独立扩展切换还需要固定版本分支建立完成。“有版本按钮”不代表已经发布了更高版本。

独立扩展：需要通过酒馆“安装扩展”使用仓库网址安装，版本管理会识别安装来源。直接解压安装的 ZIP 没有 Git 信息，需完成一次安装方式迁移；先停用并移走旧扩展目录，保存书架设置，只启用一份。不要点击清除扩展数据。

酒馆助手版：默认使用上述发布仓库，新用户不必手填。需要助手提供 getScriptTrees / updateScriptTreesWith 接口（4.8.0 起）；保留脚本原 ID、启用状态、自定义数据、按钮及其他全局脚本，只替换书架代码、名称和说明。

作者每次发布保存完整版本包和固定版本分支。独立扩展切到固定分支后停留在该版本，不跟随 main 自动升级；用户主动更新时才再切换。助手版也只在确认后更新自己的代码。

V1.4.0 原包没有“版本与更新”入口。回退前会明确提示：如需再次升级，助手版重新导入新版 JSON；独立扩展从酒馆扩展管理切回 main。V1.4.1 及以后保留版本入口。

## V1.4.0 试用版（2026-09-23）

接续 V1.3.8 的独立角色书架，重点是大量卡片下的加载和轻量分类。

- 默认每页 20 张，底部可切换 40 张。只创建当前页卡面；滚动时按索引定位角色，存档数量直接更新对应卡片。
- 「全部 ▾」中切换文件夹、查看未分类、新建文件夹。选中自建文件夹后，同一菜单可以重命名或删除。
- 电脑把卡片拖到「全部 ▾」上，待菜单展开后放入目标文件夹。已选中多张时可一起拖入。
- 点「整理」后点选角色卡，可翻页继续选、全选本页，再点「移至…」。手机可直接使用这一入口，也支持长按封面进入整理。普通上下滑动会取消长按计时。
- 文件夹为单层分类，每张角色卡或群聊归属一个文件夹。删除文件夹时卡片回到未分类。酒馆助手不参与文件夹整理。
- 文件夹筛选可与收藏、搜索、排序组合。原有置顶、收藏、封面裁切、存档显示名继续沿用。
- 分类只保存到书架设置，不移动角色文件或聊天文件，不修改角色卡标签。设置由当前酒馆账户保存；不同酒馆服务端不会自动同步。
- 默认只按需读取当前页存档数量。选择「存档最多」时，为保证全局排序，会后台读取当前筛选范围内的全部存档数量；后台计数最多三路并发。此时的首轮统计仍需要时间。

这次仍只更新独立书架和酒馆助手版，不替换砚台记忆套件。安装二选一：ZIP 覆盖原 `jingdu-bookshelf` 文件夹；助手版关闭旧脚本后导入新版 JSON，只启用一份。

## 停用与排查

取消「首页显示角色书架」可保留手动入口。完全停用时，在酒馆扩展管理中关闭本扩展并刷新。

如果仍显示旧名称或旧版本，确认覆盖了实际运行酒馆的文件夹，再强制刷新。电脑可用 Ctrl+F5，手机重新加载页面。

书架使用原生接口读取角色 / 存档、切换和新建聊天；用户确认删除时移除选中的整份存档，不改写其他存档正文或角色设定、预设、世界书。停用不会删除书架偏好。
