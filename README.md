# 砚台 · 角色书架

V1.4.4 · 创意与测试：阿砚 · 代码：Codex

让酒馆首页以 3:4 竖版角色卡展示，提供轻量角色分类与存档管理。颜色、字体跟随当前酒馆主题。原名「静读 · 角色书架」。

## V1.4.4 更新

- 书架统计栏新增原生“从文件导入”图标，直接打开酒馆的角色卡文件选择器，不离开书架。
- “全部 ▾”新增“标签视图”：按角色卡已有标签临时筛选，也提供“无标签”视图。标签视图不会新建文件夹，也不会改变手动分类；一张卡有多个标签时会出现在多个标签视图中。
- 为标签筛选保留角色卡的完整标签集合，卡片上仍只显示少量标签作为预览。
- 卡片封面工具仍保留原来的书架裁切功能，并新增“更换角色卡封面”；存档页底部增加原生风格的角色卡删除入口和二次确认。

已有角色文件的卡片可以直接替换封面；没有原始角色文件的占位卡仍请使用酒馆原生编辑页添加封面。

## V1.4.3 更新

- 新增首页浮动栏自动避让：根据工具栏和输入栏的实际位置补足空间，让顶部分组入口和底部分页可以正常操作。
- 已经留好空间的布局不重复加空白。切换主题、横竖屏、窗口尺寸变化或输入栏展开后重新测量，不持续轮询角色卡。
- 修复更新按钮禁用时鼠标仍显示转圈的问题：只有检查或切换版本期间显示等待状态。
- 保留 V1.4.2 的苹果端分类菜单与主题毛玻璃兼容修复。

布局兼容测试版已由作者在反馈场景下试用确认。完全自建的工具栏或特殊滚动布局，仍可能需要主题文件进一步适配。

## 安装与更新

现在提供 GitHub 链接安装和酒馆助手 JSON 两种方式，选一种，只启用一份书架。

### GitHub 链接安装

最低要求：SillyTavern 1.16.0。在酒馆“扩展 → 安装扩展”中粘贴：

```text
https://github.com/ayan-atelier/yantai-bookshelf
```

分支或标签留空。安装后刷新酒馆，在“扩展 → 砚台 · 角色书架”开启首页书架。

已使用 V1.4.1–V1.4.3 的用户，在书架设置的“版本与更新”中点击“检查更新”，选择“更新到 V1.4.4”，确认后刷新酒馆。原来的安装网址不变。

### 酒馆助手版

下载 [yantai-bookshelf-v1.4.4-helper.json](https://github.com/ayan-atelier/yantai-bookshelf/raw/refs/heads/main/releases/yantai-bookshelf-v1.4.4-helper.json)，导入酒馆助手的全局脚本库，开启全局脚本总开关和这份书架脚本，再刷新酒馆。

V1.4.1 及之后的助手版可在“版本与更新”中更新，需要助手提供 `getScriptTrees` / `updateScriptTreesWith` 接口（4.8.0 起）。更早的书架或不支持在线更新的助手版本可重新导入新版 JSON。

### 测试版迁移

先停用测试书架，只开启一种安装方式，保留原来的书架设置。

V1.4.4 测试版与正式版使用相同版本号，测试版不会提示同版本升级。手动安装的测试扩展停用后，启用原来的 GitHub 版检查更新；没有 GitHub 版的用户可按上方网址安装。使用助手测试脚本时，重新导入正式 JSON。只启用一份书架。

## 主要功能

- 3:4 竖版角色封面，支持置顶、收藏、封面位置调整，以及按名称和标签搜索。
- 统计栏一键导入角色卡；封面工具可更换原始角色图片；存档页可通过原生确认弹窗删除角色卡，并选择是否一并删除聊天。
- “全部 ▾”中切换分类、新建文件夹；选中自建文件夹后可以改名或删除。删除文件夹只取消分类，角色卡与聊天存档保留。
- “全部 ▾”中的标签视图按已有标签筛选，支持无标签视图；不改变手动分类。
- “整理”中多选、跨页选择和批量移动；桌面可拖动卡片到分类，手机可长按进入整理。
- 默认每页 20 张，可切换 40 张；只创建当前页卡片，按需读取存档信息。
- 支持最近游玩、最近添加、最早添加、存档最多和名称排序。置顶角色优先显示。
- 记住分类、收藏筛选、页码、排序和每页数量。临时搜索不会覆盖已保存的浏览位置。
- 同一角色的存档集中查看，支持新聊天、重命名、删除和内容预览。预览读取已有消息，不调用模型。
- 首页可切回原版；聊天中可从扩展菜单打开书架。

## 在线更新与回退

“版本与更新”只在你主动点击时联网检查或切换版本，不在启动时自动下载更新。

切换前会保存一份书架设置备份。更新与回退不主动清空当前分类、收藏、置顶、裁切等配置，不修改角色卡或聊天正文。生成、保存中，以及下载或校验失败时停止切换。

V1.4.4 的上一兼容版本为 V1.4.3。旧版本分支和发布文件保留，不用新文件覆盖。V1.4.0 原包没有版本入口，退回后如需升级，助手版重新导入新版，GitHub 版在酒馆扩展管理中切回 `main`。
