# 砚台 · 角色书架

V1.4.2 · 创意与测试：阿砚 · 代码：Codex

让酒馆首页以 3:4 竖版角色卡展示，提供轻量角色分类与存档管理。颜色、字体跟随当前酒馆主题。原名「静读 · 角色书架」。

## V1.4.2 更新

- 修复部分苹果 TauriTavern 用户在“全部 ▾”菜单中无法切换分类、新建文件夹的问题。保留方向键导航、Tab/Escape 退出和菜单外点击关闭。
- 为排序菜单补充相同的触控焦点兼容处理。
- 解除书架卡片、弹窗和遮罩对毛玻璃模糊的强制禁用，让主题自行控制效果，不统一增加每张卡片的模糊。

三位反馈者已确认分类菜单与毛玻璃的兼容测试版解决了各自的问题。不同系统、浏览器和主题组合可能有差异。

## 安装与更新

独立扩展最低要求：SillyTavern 1.16.0。扩展版与酒馆助手版选一种，只启用一份书架。

### 推荐：网址安装独立扩展

在酒馆“扩展 → 安装扩展”中粘贴：

```text
https://github.com/ayan-atelier/yantai-bookshelf
```

分支或标签留空。安装后刷新酒馆，在“扩展 → 砚台 · 角色书架”开启首页书架。

已经使用网址安装 V1.4.1 的用户，可在书架设置的“版本与更新”里检查更新，更新后刷新酒馆。

### 酒馆助手版

下载 [yantai-bookshelf-v1.4.2-helper.json](https://github.com/ayan-atelier/yantai-bookshelf/raw/refs/heads/main/releases/yantai-bookshelf-v1.4.2-helper.json)，导入酒馆助手的全局脚本库，开启全局脚本总开关及这份书架脚本，再刷新酒馆。

V1.4.1 的助手版可在“版本与更新”中更新，需要助手提供 `getScriptTrees` / `updateScriptTreesWith` 接口（4.8.0 起）。更早的书架版本可重新导入新版 JSON。

### 手动解压安装

下载 [yantai-bookshelf-v1.4.2.zip](https://github.com/ayan-atelier/yantai-bookshelf/raw/refs/heads/main/releases/yantai-bookshelf-v1.4.2.zip)，解压出 `jingdu-bookshelf` 文件夹，放进当前账户的扩展目录，例如：

```text
SillyTavern/data/default-user/extensions/jingdu-bookshelf/manifest.json
```

不要多套一层文件夹。远程访问时，安装到实际运行酒馆的设备。手动解压的扩展没有 Git 信息，在线切换版本需先改用网址安装。

### 旧版与测试版迁移

先停用旧书架，只开启一种安装方式。保留书架设置，不要清除扩展数据。

V1.4.2 兼容测试 1 与正式版使用同一个版本号，测试用户不会收到同版本升级提示：助手版重新导入正式 JSON；独立测试版停用 `yantai-bookshelf-test1`，再启用原来的网址安装版并更新。

## 主要功能

- 3:4 竖版角色封面，支持置顶、收藏、封面位置调整，以及按名称和标签搜索。
- “全部 ▾”中切换分类、新建文件夹；选中自建文件夹后可以改名或删除。删除文件夹只取消分类，角色卡与聊天存档保留。
- “整理”中多选、跨页选择和批量移动；桌面可拖动卡片到分类，手机可长按进入整理。
- 默认每页 20 张，可切换 40 张；只创建当前页卡片，按需读取存档信息。
- 支持最近游玩、最近添加、最早添加、存档最多和名称排序。置顶角色优先显示。
- 记住分类、收藏筛选、页码、排序和每页数量。临时搜索不会覆盖已保存的浏览位置。
- 同一角色的存档集中查看，支持新聊天、重命名、删除和内容预览。预览读取已有消息，不调用模型。
- 首页可切回原版；聊天中可从扩展菜单打开书架。

## 在线更新与回退

“版本与更新”只在你主动点击时联网检查或切换版本，不在启动时自动下载更新。

切换前会保存一份书架设置备份。更新与回退不主动清空当前分类、收藏、置顶、裁切等配置，不修改角色卡或聊天正文。生成、保存中，以及下载或校验失败时停止切换。

正式发布后，V1.4.2 可退回 V1.4.1。旧版本分支与安装包保留，不用新文件覆盖。V1.4.0 原包没有版本入口，退回后如需升级，助手版重新导入新版，独立扩展在酒馆扩展管理中切回 `main`。
